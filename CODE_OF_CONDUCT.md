# Community Code of Conduct

Be respectful, patient and constructive. Discuss ideas and code without personal
attacks. Harassment, threats, discrimination, sexual harassment, doxxing and
deliberate disruption are not acceptable.

Respect privacy and intellectual property. Do not post passwords, account tokens,
private messages or personal information in issues or pull requests. Follow the
same standards in reviews, discussions and project-related public spaces.

Report conduct concerns privately through a maintainer's GitHub profile contact
channel where available. Do not publish a victim's private details. Maintainers
may edit or remove harmful material, request changes, restrict participation or
ban accounts proportionately. Maintainers follow this code too.

This is the project's own short conduct policy, not a claim that a separate
moderation team or confidential reporting service already exists.
