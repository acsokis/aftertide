# AFTERTIDE development

Build an original, persistent Caribbean survival and settlement game. Player-facing
text is English. Keep simulation, geography, movement, UI and saved state separate.
Preserve stable IDs and save compatibility or supply an explicit migration.
Do not import commercial-game assets or unreviewed reference-game code/content.

Read README, docs/ARCHITECTURE, docs/SOURCES and NOTICE before subsystem changes.
Run domain checks; report actual engine/runtime checks and those not run.
No performance, visual or feature claims from compilation alone. AI helpers are
optional development tools, never required game services. Review generated work.

Use focused diffs and meaningful commits. Do not commit secrets, saves, model
weights, private prompts, caches or uncleared assets. Do not force-push or publish
releases without maintainer authorization and verified release checks.
