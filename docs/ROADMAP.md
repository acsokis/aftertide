# Roadmap

## Current experimental foundation

Original geographic starting coast; carrying, shared storage, needs, crafting,
construction, one worker, production and a ten-condition expedition/storm chapter.
Automated domain and engine tests exist. Full manual traversal and release QA
must be recorded separately before an executable release is advertised as verified.

## Next milestone

1. Complete and record the whole chapter through normal 3D input.
2. Strengthen save validation, transactional world reconstruction and corruption recovery.
3. Expand worker congestion/blocked-route tests and supported placement coverage.
4. Improve original art, water, shoreline transitions, sound and accessible UI.
5. Verify standard Godot .NET and pinned NVIDIA-fork import/export independently.
6. Profile frame-time/memory on declared hardware and improve spatial batching.
7. Resolve the working-name conflict before branding a public release.

## Later, gated by a stable local loop

Additional geographically based playable regions, travel/streaming, logistics,
multiple settlements, wildlife and richer community decisions. Networking and
advanced physics/rendering have separate compatibility and performance gates.
There are no promised dates or measured minimum FPS claims.
